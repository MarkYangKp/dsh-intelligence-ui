# Examples

Runnable OpenUI programs showing different content shapes. Paste a fence into a chat reply to
render it (see the main [README](../README.md#usage)), or open it in the gallery (`pnpm gallery`).

| File | Content shape | Demonstrates |
|---|---|---|
| `report.openui` | Weekly business report | KPI grid, area chart, table, callout |
| `report-en.openui` | Same report in English | English content with the same layout |
| `comparison.openui` | Option comparison | Side-by-side cards, comparison bars |
| `tutorial.openui` | Step-by-step tutorial | Steps, code blocks, notes |
| `ops-incident.openui` | Incident review | Timeline, callouts, diff |
| `research-brief.openui` | Research summary | Key-value facts, bullets, quote |
| `code-review.openui` | Code review | Diff, file tree, checklist |
| `code-change.openui` | Code change explanation | Code block with highlights, diff |
| `code-highlight.openui` | Syntax highlighting | Multiple languages, line highlights |
| `geo-distribution.openui` | Geographic distribution | Map with points and links |

Programs use positional arguments only. Component signatures are documented in
[docs/COMPONENTS.md](../docs/COMPONENTS.md).
